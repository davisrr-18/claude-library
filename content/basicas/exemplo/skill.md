# Skill de exemplo

Use este arquivo como modelo. Cada peça de um card é um `.md` listado no `content/manifest.json`.

## Quando usar

Descreva o gatilho da skill em uma ou duas frases.

## Passos

2. Segundo passo.

## Exemplo de comando

```bash
# copie a skill para a pasta de skills do Claude Code
mkdir -p ~/.claude/skills/exemplo
cp skill.md ~/.claude/skills/exemplo/SKILL.md
```

> Dica: use o botão **Copiar** no canto do bloco.
