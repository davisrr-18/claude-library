# Claude Library

Biblioteca pessoal para guardar e consultar as propostas que eu monto para o Claude Code (skills, agentes, workflows, prompts, `CLAUDE.md` e arquiteturas), organizadas por complexidade da tarefa: **Básicas**, **Intermediárias** e **Complexas**.

Site estático em React + Vite (`client/`), com o conteúdo em Markdown em `content/` e publicação no GitHub Pages. Para rodar: `npm install` e `npm run dev` (abre em `http://localhost:5173`). Regras, arquitetura e decisões: `CLAUDE.md`, `arquitetura.md` e `docs/`.
