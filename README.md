# Claude Library

Biblioteca pessoal, em HTML, CSS e JavaScript puros, para guardar e consultar as propostas que eu monto para o Claude Code (skills, agentes, workflows, prompts, `CLAUDE.md` e arquiteturas), organizadas por complexidade da tarefa: **Básicas**, **Intermediárias** e **Complexas**.

O site está migrando para React + Vite em `client/` (ver `docs/decisions/`); o site publicado ainda é o antigo, sem build e sem dependências de execução. Os dois pacotes de terceiros estão em `vendor/` (marked e highlight.js, com versão e licença em `vendor/README.md`).
